The kitchen display for café tablets. Staff only.

 

Download APK
  1. Open this page in Chrome on the tablet and tap Download APK.
  2. Open the downloaded file. If Android asks, allow Chrome to install unknown apps, then go back and open it again.
  3. To update later, download and install the new file the same way. The app keeps its settings.

A tablet with the Google Play version installed must uninstall it first. The two are signed differently and cannot update each other.
